# GrowthCred AI search prompt tracker

Run these prompts on the first of each month in ChatGPT, Claude, Perplexity and Gemini. Use a fresh chat and the same South Africa context. For every prompt/product pair, append one row to [query-log.csv](query-log.csv) with the date, product and model, exact prompt, whether GrowthCred was named, whether `growthcred.co.za` was cited, the other providers named and the source URLs. That is 68 rows for a complete monthly run. A response may both name and cite GrowthCred.

Use `Y` or `-` separately for **Named** and **Cited** in this quick-view template. In the CSV, use `Y` or `N` in each matching field. Record the answer itself only as much as needed to explain a change or factual error. These runs are a small, variable sample; they do not measure market share or guarantee that a future answer will be the same.

## Baseline supplied 13 October 2026

The supplied audit says Brave did not return GrowthCred for a branded search, while DuckDuckGo's Bing-backed results listed the site. The audit could not complete live ChatGPT or Perplexity checks because those products required sign-in or a human check. This is an owner-provided baseline, not a fresh verification by this tracker.
